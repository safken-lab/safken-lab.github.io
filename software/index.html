Software

  • DeepTab (Mambular)

    Python

    A library for classification, regression, and distributional prediction on tabular data. It includes Mamba-style state-space models, transformers, and other architectures with a scikit-learn-style interface.

  • NAMpy

    Python

    Interpretable additive models for tabular data. NAMpy provides classical generalized additive models and neural additive models for regression, classification, and distributional regression through a common estimator interface.

  • STREAM

    Python

    A toolkit for fitting, evaluating, and interactively exploring topic models. Its visualizations help compare topics and inspect how they relate to one another.

  • cAIC4

    R

    Computes conditional Akaike information criteria for mixed-effects models and supports stepwise model selection. It works with models fitted using packages such as lme4, nlme, and gamm4.

  • NODE-GAMLSS

    Python

    Fits interpretable models for location, scale, and shape using differentiable decision trees. The implementation estimates conditional distribution parameters by minimizing negative log-likelihood.

  • TNTM

    Python

    The Transformer-Representation Neural Topic Model combines contextual embeddings with probabilistic topic modelling. The repository includes bag-of-words and sentence-transformer variants.

  • TTLocVis

    Python

    A toolkit for working with geolocated Twitter data. It prepares text for LDA topic modelling and shows how topic prevalence changes across locations and over time.
